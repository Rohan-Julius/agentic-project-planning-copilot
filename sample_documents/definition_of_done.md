# Definition of Done

Work on a story is complete only when all of the following are true:

1. All acceptance criteria pass, verified by automated tests where practical.
2. Code has been peer-reviewed and approved by at least one other engineer.
3. Unit tests cover the new logic; integration tests cover the new user-facing behavior.
4. No new critical or high-severity static-analysis findings were introduced.
5. Documentation (API docs, README, or inline comments) is updated to reflect the change.
6. The change has been deployed to a staging environment and manually smoke-tested.
7. Any new configuration or environment variables are documented in the deployment guide.
8. The story's acceptance criteria are demonstrated to the product owner before close.
